# 🔧 Учётные записи инженеров

## Демо-инженеры

Для тестирования системы с точки зрения сотрудника ИТ доступны следующие учётные записи:

| Логин | Имя | Пароль |
|-------|-----|--------|
| `voronin.d` | Воронин Денис | `engineer123` |
| `ivanov.i` | Иванов Иван | `engineer123` |
| `petrov.s` | Петров Сергей | `engineer123` |
| `sidorova.a` | Сидорова Анна | `engineer123` |
| `kozlov.m` | Козлов Михаил | `engineer123` |

## Как войти под инженером

1. На странице входа введите логин инженера (например, `voronin.d`)
2. Введите пароль: `engineer123`
3. Нажмите "Войти"

В шапке появится бейдж **"🔧 Инженер"** рядом с именем.

## Возможности инженера

### 1. Панель инженера в детальной карточке заявки

При открытии заявки инженер видит дополнительную панель с быстрыми действиями:

- **⏰ Взять в работу** — меняет статус на "В работе" и назначает себя инженером
- **✅ Решить проблему** — меняет статус на "Решена"
- **❌ Закрыть заявку** — меняет статус на "Закрыта"

### 2. Изменение статуса

Инженер может менять статус любой заявки через выпадающий список в боковой панели.

### 3. Комментарии от имени инженера

Все комментарии инженера отображаются с его именем и могут содержать скриншоты.

## Сценарий тестирования

### Сценарий 1: Полный цикл работы с заявкой

**Шаг 1: Создание заявки (пользователь)**
1. Войдите под обычным пользователем (например, `testuser` / `123`)
2. Создайте заявку:
   - Тип: Инцидент
   - Тема: "Не работает принтер"
   - Описание: "Принтер в кабинете 305 не печатает"
   - Приоритет: Высокий
   - Локация: МОФ
   - Категория: Оргтехника и принтеры
3. Нажмите "Отправить заявку"

**Шаг 2: Обработка заявки (инженер)**
1. Выйдите из системы
2. Войдите под инженером: `voronin.d` / `engineer123`
3. Найдите созданную заявку в списке
4. Кликните на неё для открытия детальной карточки
5. В панели инженера нажмите **"Взять в работу"**
   - Статус изменится на "В работе"
   - Инженер автоматически назначен
6. Добавьте комментарий: "Принял в работу. Приду через 15 минут"
7. Нажмите Enter для отправки

**Шаг 3: Решение проблемы (инженер)**
1. Добавьте комментарий с результатом: "Проблема решена. Был замят лист бумаги"
2. Прикрепите скриншот (если нужно)
3. Нажмите **"Решить проблему"**
4. Статус изменится на "Решена"

**Шаг 4: Проверка (пользователь)**
1. Выйдите и войдите под пользователем `testuser`
2. Откройте заявку
3. Убедитесь, что видите все комментарии инженера
4. Проверьте, что статус "Решена"

### Сценарий 2: Общение через комментарии

1. Пользователь создаёт заявку
2. Инженер берёт её в работу
3. Пользователь добавляет комментарий с уточнением
4. Инженер отвечает на комментарий
5. Обмен продолжается до решения проблемы

### Сценарий 3: Назначение другого инженера

1. Инженер открывает заявку
2. В боковой панели меняет поле "Инженер" на другого сотрудника
3. Добавляет комментарий: "Передаю коллеге, он специализируется на сетях"

## Технические детали

### Как это работает

1. При первом запуске приложения в localStorage создаются 5 предустановленных инженеров
2. При входе система проверяет, совпадает ли логин с одним из инженеров
3. Если совпадает — устанавливается роль `engineer` и соответствующее полное имя
4. Если не совпадает — создаётся обычный пользователь с ролью `user`

### Хранение данных

Инженеры хранятся в localStorage в массиве `sd_employees` с полем `role: 'engineer'`.

### Сброс данных

Если нужно сбросить всех инженеров:
1. Откройте консоль браузера (F12)
2. Выполните:
   ```javascript
   localStorage.removeItem('sd_employees');
   localStorage.removeItem('sd_user');
   localStorage.removeItem('sd_tickets');
   location.reload();
   ```
3. Инженеры будут созданы заново при следующем запуске

## Добавление новых инженеров

Для добавления нового инженера отредактируйте файл `src/App.tsx`:

```typescript
const DEFAULT_ENGINEERS = [
  { username: 'voronin.d', fullName: 'Воронин Денис', department: 'Отдел ИТ', role: 'engineer' },
  { username: 'ivanov.i', fullName: 'Иванов Иван', department: 'Отдел ИТ', role: 'engineer' },
  // Добавьте нового инженера:
  { username: 'new.engineer', fullName: 'Новый Инженер', department: 'Отдел ИТ', role: 'engineer' },
];
```

После изменения:
1. Очистите localStorage (см. выше)
2. Перезагрузите страницу
3. Новый инженер будет доступен для входа

## Интеграция с Active Directory

В продакшене роль инженера должна определяться через Active Directory:
- Группа "IT-Engineers" в AD → роль `engineer`
- Группа "IT-Admins" в AD → роль `admin`
- Все остальные → роль `user`

Для этого нужно реализовать бэкенд-сервер с LDAP-интеграцией (см. `DATABASE_SETUP.md`).
