# 📋 Инструкция по использованию Service Desk

## 🆕 Новые возможности

### 1. Детальный просмотр заявки
- **Кликните на любую заявку** в списке, чтобы открыть детальную карточку
- В модальном окне отображается:
  - Полная информация о заявке (тема, описание, приоритет, категория)
  - Статус и возможность его изменить
  - Информация о заявителе и инженере
  - Локация и крайний срок (если указан)
  - Дата создания и последнего обновления

### 2. Комментарии
- В нижней части детальной карточки находится раздел **"Комментарии"**
- Заявитель и исполнитель могут общаться через комментарии
- Каждый комментарий отображает:
  - Имя автора
  - Время отправки
  - Текст сообщения
  - Прикреплённые изображения (если есть)

**Как добавить комментарий:**
1. Введите текст в поле "Напишите комментарий..."
2. Нажмите **Enter** для отправки (или **Shift+Enter** для новой строки)
3. Или нажмите кнопку **"Отправить"**

### 3. Прикрепление изображений
- Нажмите кнопку **"📷 Фото"** рядом с полем комментария
- Выберите одно или несколько изображений (PNG, JPG, GIF)
- Максимальный размер файла: **5 МБ**
- Изображения отображаются в виде миниатюр перед отправкой
- Можно удалить прикрепление, нажав на крестик в углу миниатюры
- После отправки комментария изображения сохраняются вместе с ним

**Просмотр изображений:**
- Кликните на миниатюру изображения в комментарии
- Откроется полноэкранный просмотр с возможностью закрыть (крестик или клик вне изображения)

### 4. Изменение статуса заявки
- В правой панели детальной карточки есть выпадающий список **"Статус"**
- Доступные статусы:
  - 🔵 **Новая** — заявка только что создана
  - 🟡 **В работе** — инженер начал работу
  - 🟢 **Решена** — проблема устранена
  - ⚫ **Закрыта** — заявка завершена
- Изменение статуса автоматически обновляется в списке заявок

### 5. Счётчик комментариев
- На карточке заявки в списке отображается иконка 💬 с количеством комментариев
- Это помогает быстро оценить активность по заявке

## 🎯 Сценарии использования

### Сценарий 1: Заявитель создаёт заявку
1. Войдите в систему
2. Нажмите **"Новая заявка"**
3. Заполните форму:
   - Выберите тип: **Инцидент** (что-то не работает) или **Запрос услуги**
   - Укажите тему и описание проблемы
   - Выберите приоритет (Низкий/Средний/Высокий/Критический)
   - Укажите локацию и категорию
   - При необходимости добавьте крайний срок
4. Нажмите **"Отправить заявку"**
5. Заявка появится в списке с номером SD-00001

### Сценарий 2: Инженер работает с заявкой
1. Кликните на заявку в списке
2. Изучите описание проблемы
3. Измените статус на **"В работе"**
4. Добавьте комментарий: "Принял в работу, приступаю к диагностике"
5. После решения проблемы:
   - Добавьте комментарий с описанием выполненных действий
   - Измените статус на **"Решена"**

### Сценарий 3: Общение через комментарии
1. Откройте заявку
2. В разделе "Комментарии" напишите сообщение
3. При необходимости прикрепите скриншот:
   - Нажмите **"📷 Фото"**
   - Выберите файл
   - Изображение появится в виде миниатюры
4. Нажмите **Enter** или **"Отправить"**
5. Все участники увидят новый комментарий

### Сценарий 4: Добавление скриншотов
**При создании комментария:**
- Нажмите **"📷 Фото"**
- Можно выбрать несколько файлов одновременно
- Файлы отображаются в виде миниатюр
- Можно удалить ненужные перед отправкой
- После отправки изображения сохраняются с комментарием

**Просмотр изображений:**
- Кликните на миниатюру в комментарии
- Откроется полноэкранный просмотр
- Нажмите крестик или кликните вне изображения для закрытия

## 💡 Советы

1. **Описание проблемы** — будьте максимально конкретны:
   - Что именно не работает?
   - Когда это началось?
   - Какие шаги предпринимали?
   - Что ожидали увидеть?

2. **Приоритет** — выбирайте обоснованно:
   - **Низкий** — не срочная задача, можно подождать
   - **Средний** — обычная задача в рабочем порядке
   - **Высокий** — мешает работе, нужна быстрая реакция
   - **Критический** — полная остановка работы, требуется немедленное вмешательство

3. **Комментарии** — используйте для:
   - Уточнения деталей
   - Отчёта о прогрессе
   - Прикрепления скриншотов ошибок
   - Подтверждения решения проблемы

4. **Скриншоты** — очень помогают:
   - Показывают точную ошибку
   - Ускоряют диагностику
   - Помогают избежать недопонимания

## 🔧 Технические детали

### Хранение данных
- **Демо-режим** (без настройки БД): данные хранятся в localStorage браузера
- **С Supabase**: данные хранятся в облачной базе данных PostgreSQL

### Ограничения
- Максимальный размер изображения: **5 МБ**
- Поддерживаемые форматы: PNG, JPG, GIF, WebP
- В демо-режиме изображения хранятся как base64 (может замедлить работу при большом количестве)

### Синхронизация
- В демо-режиме данные синхронизируются локально
- При использовании Supabase данные доступны с любого устройства

## 🐛 Решение проблем

### Заявка не открывается
- Обновите страницу (F5)
- Очистите данные через кнопку "Настроить БД" → "Очистить все данные"

### Изображение не загружается
- Проверьте размер файла (максимум 5 МБ)
- Убедитесь, что файл является изображением
- Попробуйте другой формат (PNG вместо JPG)

### Комментарии не сохраняются
- Проверьте подключение к интернету (для Supabase)
- В демо-режиме убедитесь, что localStorage не переполнен

## 📞 Поддержка

Если возникли вопросы или проблемы:
1. Проверьте консоль браузера (F12) на наличие ошибок
2. Очистите данные через кнопку "Настроить БД"
3. Перезагрузите страницу
4. Обратитесь к администратору системы
